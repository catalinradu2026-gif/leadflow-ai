## 1. Pentru depunerea ofertei — dosarul este complet

Se depun documentele din cele două mape (vezi opisul). Nu sunt necesare alte acțiuni pentru depunere.

- [x] Prezentare funcțională și descriere completă a soluției
- [x] Documentație tehnică și manuale de utilizare
- [x] Conformitate GDPR + suita de documente juridice (DPA, DPIA, Registru, Retenție, Transfer, DPO)
- [x] Confruntarea conținutului cu cei 24 de indicatori oficiali
- [x] Găzduire și domeniu · Opis de dosar

---

## 2. La semnarea contractului — se completează de părți

Documentele juridice sunt redactate în formă finală; la contractare se completează doar rubricile de semnătură:

- [ ] Semnarea **Acordului de prelucrare (DPA)** de către ambele părți (ARACIP + NEWTIME).
- [ ] Emiterea **deciziei de desemnare a DPO** de către ARACIP și înscrierea numelui persoanei desemnate.
- [ ] Semnături, dată, ștampile, numărul contractului principal.

---

## 3. Decizii ale operatorului (la contractare)

- [ ] **Domeniul oficial** — subdomeniu `*.aracip.ro`, cu acces DNS.
- [ ] **Găzduirea de producție** — Vercel + Supabase (UE) la start / migrare la operarea națională.
- [ ] **Cont Groq pe firmă (tarif plătit)** — pentru arhiva verbatim a asistentului ARA și robustețe la trafic.

---

## 4. După câștigarea licitației — implementare

Plan detaliat în documentul „De făcut după câștigarea licitației":

- [ ] Bază de date pe **plan plătit** (backup automat) + **conturi individuale** per utilizator.
- [ ] **Import în masă** al celor ~1.000 de unități + evaluatori.
- [ ] Backup automat, **SLA**, monitorizare disponibilitate.
- [ ] Instruire pe roluri + go-live național.
